# Agent guidance

- Treat doctrinal, policy, and historical assertions as claims requiring traceable sources; distinguish source text, interpretation, and inference.
- Preserve provenance and version history. Do not silently rewrite prior evidence or invent citations.
- For rule or policy changes, include positive, negative, boundary, and regression tests where practical.
- Fail clearly when a required source, license decision, or validation input is missing. Do not invent a license or weaken a checker to bypass missing metadata.
- Follow `.agents/skills/verification-gates/SKILL.md` and `.agents/skills/policy-auditability/SKILL.md`.
